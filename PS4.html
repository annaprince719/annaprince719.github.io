Problem I: Interpreting Results

Ref: https://www.ripublication.com/ijss16/ijssv11n2_05.pdf and https://psy652.colostate.edu/modules/m13-categorical_predictors.html (with interpretation from AI). Since problem gives 1-0, not -1, this is dummy coding not effect coding.

So y = 10 + 5x + 4s + 3r + 2sr where either sex or region can be 1 or 0. Intercept = 10, slope = 5, e_{s} = 4, e_{r} = 3, e_{sr} = 2

Now you want to rewrite this as y = int + 5 + e_{NM} + e_{NF} + e_{SF}, where NMSF are all 0-1 manifestations of SR (M = 1, N = 1, else 0)

SF: If s,r = 0 then y = 5x + 10 NM: If s,r = 1 then y = 10 + 5x + 4 + 3 + 2 = 5x + 19 NF: If s = 0, r = 1 then y = 10 + 5x + 3 = 5x + 13 ##SM: If s = 1, r = 0 then y = 10 + 5x + 4 = 5x + 14

Note “dummy variable trap”: you can only find effects with a reference group, which should be SM if it’s the one left out of the original model.

5x is constant, intercept is the average of all the groups = (10+19+13+14)/4 = 14, and coefficients are the difference from that average.

SF: 10 - 14 = -4 NM: 19 - 14 = 5 NF: 13 - 14 = -1 SM: 14 - 14 = 0 (this makes sense because it does not appear in the original)

So rewrite as y = 14 + 5x + 5NM - NF - 4SF.

We just recoded the variables, not changed the actual underlying model, so anything we do regression-wise shouldn’t change, including the results of whatever hypothesis test.

Problem II: Constrained vs. Unconstrained Models

a). Matrix formulation

Ref: W5 slides 28-31

\[ \hat{\gamma} = C \hat{\beta} \]

We’re testing two hypotheses (B_{1} = 0 AND B_{2} + .5B_{3} = 1), so we need two rows for C. Then the second matrix is just symbolic because we haven’t been given real coefficients.

\[ \hat{\gamma} = \begin{pmatrix} 1 & 0 & 1 & 1 \\ 0 & 0 & 1 & 0.5 \end{pmatrix} \begin{pmatrix} \hat{\beta}_0 \\ \hat{\beta}_1 \\ \hat{\beta}_2 \\ \hat{\beta}_3 \end{pmatrix} \]

b). Do residual squares say anything about the validity of the model constraints?

An unconstrained model should have higher residuals, since there’s naturally less variance when you “lock something down.” Lower residuals mean the constrained model fits better, not worse, so the constraint is “true” in the sense it actually improves the model fit.

library(foreign)

df <- data.frame(read.dta("/Users/margaretprince/Downloads/pIII_room.dta"))

F_test <- function(ESS1, ESS2){
  F <- (ESS2 - ESS1)/(ESS1/28)
  return(F) 
}

ESS1 <- deviance(lm(rentper ~ sex + roomper + dist, data = df))
ESS2 <- deviance(lm(rentper ~ roomper + dist, data = df))

paste0("F-value = ", F_test(ESS1, ESS2))
[1] "F-value = 1.44957934600403"

So the calculated F-statistic is 1.45, and the F-table for (1,28) returns 2.8. Since 1.45 isn’t in the rejection region, we can’t reject the null hypothesis that “gender does not influence housing demand.” This is the same logic and conclusion as the t-test above.

F-test is a ratio of variance, while t-test is a ratio of means, so both must be positive since dividing by the same sign. (Note: Google has pointed out that F = t^2, which is the case in the above (1.2*1.2 is 1.45), but I cannot find mathematical reasoning to explain this. It also does not make sense given that there can significant variety within the same means, i.e. the means of 49/51 and 25/75 are both 50).
